# Task-12: Missing Value Identification

## Project Overview
This project focuses on identifying missing values in the Titanic dataset using Python and Pandas in Google Colab.

## Objective
To identify missing values, calculate missing-value counts and percentages for each column, and summarize the results.

## Dataset
- **Dataset Name:** Cleaned Titanic Dataset
- **File Name:** `cleaned_titanic.csv`
- **Rows:** 891
- **Columns:** 11

## Tools Used
- Python
- Pandas
- Google Colab

## Steps Performed
1. Imported the Pandas library.
2. Loaded the cleaned Titanic dataset.
3. Displayed the first five rows of the dataset.
4. Identified missing values in each column.
5. Calculated the percentage of missing values.
6. Generated a summary of the results.

## Results
- Total rows: 891
- Total columns: 11
- Total missing values: 0
- No missing values were found in the current cleaned dataset.

## Conclusion
The missing value identification task was completed successfully using Python and Pandas. The analysis showed that the cleaned Titanic dataset contains no missing values. Therefore, no additional missing-value treatment was required for this dataset.
