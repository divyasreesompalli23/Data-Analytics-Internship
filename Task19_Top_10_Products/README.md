# Task 19 – Top 10 Products by Sales

## Project Overview
The objective of this task is to identify the top 10 products based on total sales using the Superstore dataset. The analysis helps understand which products generate the highest sales.

## Objective
- Analyze product-wise sales data.
- Calculate total sales for each product.
- Identify the top 10 products by sales.
- Visualize the results using a bar chart.
- Present the findings in a clear and understandable format.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Microsoft Excel
- Microsoft Power BI
- GitHub

## Dataset
The Superstore sales dataset is used for this analysis. It contains product details and sales information.

## Project Workflow
1. Load the dataset.
2. Inspect and prepare the data.
3. Group the data by product name.
4. Calculate total sales for each product.
5. Sort products by total sales in descending order.
6. Select the top 10 products.
7. Create a bar chart to visualize the results.
8. Export the results for further analysis.

## Key Deliverables
- Python analysis notebook (`.ipynb`)
- Top 10 products results (`.csv`)
- Excel workbook (`.xlsx`)
- Power BI report (`.pbix`), if created
- README documentation

## Result
The analysis identifies the 10 products with the highest total sales and presents the results using a chart and tabular output.

## Conclusion
This project demonstrates how data analysis and visualization techniques can be used to identify top-performing products and understand sales performance.
