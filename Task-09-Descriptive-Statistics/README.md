# Task 09 – Descriptive Statistics Primer

## Objective

Calculate and interpret descriptive statistics for numerical columns in a dataset.

## Tool Used

* Microsoft Excel

## Dataset

Titanic-style passenger dataset (sample dataset).

## Columns Analyzed

* Age
* Fare
* SibSp
* Parch

## Statistics Calculated

* Count
* Mean
* Median
* Mode
* Standard Deviation
* Minimum and Maximum
* 25th, 50th, and 75th Percentiles

## Key Findings

* Average passenger age is approximately 32.02 years.
* Fare mean is greater than its median, suggesting right skewness.
* Fare values show considerable variation.
* Percentiles help describe the distribution and spread of fares.

## Conclusion

This project demonstrates how descriptive statistics help summarize numerical data and understand the center, spread, and skewness of a dataset.
