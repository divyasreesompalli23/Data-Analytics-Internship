# Task 10 - Simple KPI Tracking Sheet

## Project Overview
This project focuses on creating a simple KPI (Key Performance Indicator) tracking sheet using Microsoft Excel. It summarizes raw sales data into important business metrics for easy monitoring and decision-making.

## Objectives
- Calculate Total Revenue.
- Calculate Total Units Sold.
- Calculate Average Order Value.
- Identify the Top Product based on total sales.
- Create a single-page KPI summary sheet.
- Use formulas to update KPI values automatically when new data is added.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## KPIs Tracked
1. **Total Revenue** – Total sales revenue generated.
2. **Units Sold** – Total quantity of products sold.
3. **Average Order Value (AOV)** – Total Revenue divided by the number of unique orders.
4. **Top Product** – Product with the highest total sales.

## Excel Functions Used
- `SUM()` – Calculates total revenue and units sold.
- `AVERAGEIF()` / appropriate order-level calculation – Supports average order value calculations.
- `SUMIF()` – Calculates total sales for each product.
- `MAX()` and `INDEX/MATCH()` – Helps identify the top-selling product.

## Key Outcomes
- Created a one-page KPI summary sheet.
- Organized key sales metrics in a clear format.
- Practiced Excel formulas and sales data analysis.
- Developed a foundation for tracking business performance.

## Conclusion
This project demonstrates how Excel can transform raw transactional data into meaningful KPIs. The summary helps users monitor revenue, sales volume, average order value, and top-performing products.
